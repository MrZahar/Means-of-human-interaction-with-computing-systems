# Проверка перевода RU/EN

1. Запустите `npm install`, затем `npm run dev`.
2. Откройте главную страницу. Вверху нажмите **RU**: должны появиться «Главная», «Каталог», «Пользователи», «Заказы», а заголовок главной страницы станет русским.
3. Нажмите **EN**: заголовок и меню должны переключиться на английский.
4. Откройте `/catalog`, `/favorites`, `/cart`, `/users`, `/orders` и повторите переключение.
5. Перезагрузите страницу — выбранный язык должен сохраниться.
6. Если текст не меняется, выполните `Ctrl + Shift + R`, затем проверьте ошибки в F12 → Console и убедитесь, что запущена папка `lab-4` именно из этого архива.

**Примечание.** Имена и email пользователей и введённые вручную названия/описания товаров не переводятся автоматически. Русские переводы для шести исходных товаров указаны в `src/i18n/productText.js`.
