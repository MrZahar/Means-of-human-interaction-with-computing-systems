# Полные переводы RU/EN

Языковые словари: `src/i18n/index.js`. Перевод исходных товаров из JSON: `src/i18n/productText.js` (не изменяет структуру `products.json`).

JSX-компоненты уже подключены к `useTranslation()`. Кнопка RU/EN в `Navbar.jsx` меняет язык и сохраняет его в localStorage.

Для запуска: `npm install`, затем `npm run dev`. Компоненты пользователей и заказов продолжают работать через Redux Toolkit. Дополнительные записи, созданные вручную, не переводятся автоматически: пользовательский контент сохраняется таким, каким был введён.

Если имеются собственные изменения после исходного `lab-4.zip`, сравните файлы перед заменой.
